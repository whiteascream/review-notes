## 必背清单（考前一眼）

**性质与静力学**

- 牛顿内摩擦定律 $\tau=\mu\dfrac{du}{dy}$，动力黏度 $\mu$ 单位 Pa·s
- 静压 $p=p_0+\rho gh$；等压面只适用于静止、连通、同种流体
- 平面总压力 $F=\rho gh_cA$，作用点 $y_D=y_c+\dfrac{J_c}{y_cA}$（$J_c$ 是形心轴惯性矩）

**三大方程**

- 连续性 $A_1v_1=A_2v_2$（不可压缩）
- 伯努利（实际流体）$z_1+\dfrac{p_1}{\rho g}+\dfrac{v_1^2}{2g}=z_2+\dfrac{p_2}{\rho g}+\dfrac{v_2^2}{2g}+h_w$
- 动量方程 $\sum F=\rho Q(v_2-v_1)$，注意矢量方向与正负号

**损失**

- 达西-魏斯巴赫 $h_f=\lambda\dfrac{l}{d}\dfrac{v^2}{2g}$
- 层流（圆管）$\lambda=\dfrac{64}{Re}$；湍流查莫迪图或柯尔布鲁克公式
- 局部损失 $h_j=\zeta\dfrac{v^2}{2g}$，突然扩大 $\zeta=\left(1-\dfrac{A_1}{A_2}\right)^2$

**相似与泵**

- 雷诺数 $Re=\dfrac{\rho vd}{\mu}=\dfrac{vd}{\nu}$，圆管临界 2320
- 弗劳德数 $Fr=\dfrac{v}{\sqrt{gL}}$；重力主导用 Fr 相等，黏性主导用 Re 相等
- 泵相似定律 $Q\propto n$，$H\propto n^2$，$P\propto n^3$
- 防汽蚀条件 $NPSH_a>NPSH_r$，安装高度 $H_g\le\dfrac{p_a-p_v}{\rho g}-NPSH_r-h_w$

## 高频考点

- 控制体选取：题目问「壁面受力」必用动量方程，问「流量/速度」先用连续性+伯努利。
- 伯努利方程只沿一条流线成立；两截面间有泵或水轮机时要加 $H_p$ / 减 $H_t$。
- 单位坑：$\rho g h$ 得到 Pa；水头形式要除以 $\rho g$，做题时先把单位统一到 SI。
- 串联管路流量相等、总损失相加；并联管路损失相等、流量分配反比于阻抗。
- 曲面总压力分解为水平分力（投影面）+ 竖直分力（压力体）。
