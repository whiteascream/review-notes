# 数值分析

> 全是「用有限步四则运算逼近真解」。考试只考两件事：**会不会构造算法**、**误差有多大**。

## 必背清单（考前一眼）

**求根**

- 二分法 $n$ 次后误差 $\le \dfrac{b-a}{2^n}$
- Newton $x_{k+1}=x_k-\dfrac{f(x_k)}{f'(x_k)}$，单根附近**平方收敛**；重根降为线性
- 不动点迭代收敛的充分条件：$|\varphi'(x)|<1$（局部），且 $|e_{k+1}|\approx|\varphi'(\xi)||e_k|$

**插值**

- Lagrange 余项 $R_n(x)=\dfrac{f^{(n+1)}(\xi)}{(n+1)!}\,\omega_{n+1}(x)$，$\omega_{n+1}=\prod(x-x_i)$
- $n+1$ 个节点唯一确定次数不超过 $n$ 的插值多项式
- Newton 差商表：一阶 $f[x_i,x_{i+1}]=\dfrac{f_{i+1}-f_i}{x_{i+1}-x_i}$

**积分**

- 梯形 $T=\dfrac{b-a}{2}[f(a)+f(b)]$，误差 $-\dfrac{(b-a)^3}{12}f''(\xi)$
- Simpson $S=\dfrac{b-a}{6}[f(a)+4f(\tfrac{a+b}{2})+f(b)]$，误差 $-\dfrac{(b-a)^5}{2880}f^{(4)}(\xi)$
- 代数精度：梯形 1 次，Simpson 3 次

**迭代法**

- 收敛条件 $\rho(B)<1$；Jacobi 与 G-S 的迭代矩阵不同，谱半径不同
- SOR 参数 $\omega\in(0,2)$，$\omega=1$ 退化为 Gauss-Seidel；超松弛 $\omega>1$
- 条件数 $\mathrm{cond}(A)=\|A\|\,\|A^{-1}\|$，越大越病态

**ODE**

- 改进 Euler（预测-校正）局部误差 $O(h^3)$
- 经典 RK4：$y_{k+1}=y_k+\dfrac{h}{6}(K_1+2K_2+2K_3+K_4)$
- 绝对稳定性：测试方程 $y'=\lambda y$ 要求 $|R(z)|\le1$，$z=\lambda h$

## 高频考点

- 误差题：先写出误差阶，再套「有效数字」定义，别把绝对误差和相对误差混用。
- 手算迭代：保留 6 位小数，最后一步再四舍五入；中间步骤提前舍入会被扣分。
- LU 分解与列主元：主元过小必须换行，否则误差爆炸——这是「为什么用列主元」的标准答案。
- 最小二乘：先构造法方程 $A^TAx=A^Tb$，再解；题目给数据点用 $\sum$ 形式手算。
- 收敛阶证明：写 $e_{k+1}=\varphi(x_k)-\varphi(x^*)$ 再 Taylor 展开，看最低非零阶。

## 考试范围（2025-12-25 老师划重点，录音纪要）

> 两场连讲：[exam/2025-12-25-考前划重点-插值逼近积分与常微分方程.docx](exam/2025-12-25-考前划重点-插值逼近积分与常微分方程.docx)、[exam/2025-12-25-考前划重点-方程求根与考试安排.docx](exam/2025-12-25-考前划重点-方程求根与考试安排.docx)

**明确不考**：迭代加速、一致逼近、埃尔米特插值的硬公式推导、复化 Simpson 公式（无需识记）、龙贝格公式、数值微分、高阶 Runge-Kutta 公式、高阶方程与方程组、球坐标、勒让德多项式构造。

**必考 / 重点**：

| 板块 | 要求 |
|---|---|
| 差商与牛顿插值 | 差商三性质（与节点顺序无关、可递推、与 n 阶导数对应）；牛顿插值只需 2–3 阶；余项与拉格朗日余项等价 |
| 埃尔米特插值 | 只考「部分节点给函数值、部分节点同时给导数值」的混合约束题型；两种解法：继承法 / 直接设多项式代入条件 |
| 函数逼近 | 最佳平方逼近（子空间法方程，内积为积分）与离散最小二乘（内积为求和）**推导逻辑完全一样**；$Y=Ae^{Bx}$ 对数变换线性化 |
| 数值积分 | 代数精度定义与判定（代 1、x、x² 试到不成立）；梯形/Simpson 公式及余项；**复化梯形内部节点系数 2 别丢**，余项 $-\frac{(b-a)h^2}{12}f''(\xi)$；高斯公式 $2n+1$ 阶 |
| 常微分方程 | 显式/隐式/梯形欧拉、改进欧拉（精度≤2 阶）；局部截断误差 $O(h^{p+1})$ → 精度 $p$ 阶；单步法收敛判据：增量函数关于 $y$ 满足 Lipschitz |
| 方程求根 | 二分法误差 < 区间一半、次数取对数；全局收敛（区间自映射 + Lipschitz 或 $|\varphi'|\le q<1$）、局部收敛（$|\varphi'(x^*)|<1$）、收敛阶（看 $x^*$ 处各阶导数为 0 的个数，$p=1$ 线性、$p=2$ 平方）；牛顿法局部平方收敛 |

**易错点**

- 最小二乘里若基函数第一个是 $1$，内积 $\langle1,1\rangle$ = **数据点个数 $n$**，不是 1。
- 计算题**必须用题目指定的方法**（要求拉格朗日就不能用牛顿），否则扣分。
- 难度低于平时作业，无超纲题；考试时间 12 月 31 日上午。

## 本次考试（2025-12-31）考了什么

14 道（回忆里题号打了两个「第五题」，故编到 14 为止）：
