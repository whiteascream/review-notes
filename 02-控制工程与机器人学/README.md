## 必背清单（考前一眼）

**时域**

- 二阶系统 $\sigma\%=e^{-\pi\zeta/\sqrt{1-\zeta^2}}\times100\%$
- 峰值时间 $t_p=\dfrac{\pi}{\omega_n\sqrt{1-\zeta^2}}$，调节时间 $t_s\approx\dfrac{4}{\zeta\omega_n}$（2% 误差带）
- 劳斯判据：首列符号变化次数 = 右半平面极点数；出现全零行用辅助方程求导

**稳态误差**

- $e_{ss}=\lim_{s\to0}sE(s)$，需先判稳
- 0 型对阶跃 $e_{ss}=\dfrac{1}{1+K_p}$；Ⅰ 型对斜坡 $\dfrac{1}{K_v}$；Ⅱ 型对加速度 $\dfrac{1}{K_a}$
- 提高开环增益可减小误差，但会降低稳定裕度——这就是校正存在的理由

**频域**

- 截止频率 $\omega_c$：$|G(j\omega_c)|=1$；相位裕度 $\gamma=180°+\angle G(j\omega_c)$
- 幅值裕度 $K_g=-20\lg|G(j\omega_g)|$，$\omega_g$ 为 $-180°$ 处频率
- 工程上 $\gamma\in[30°,60°]$ 比较稳妥

**校正**

- 超前校正最大相角 $\varphi_m=\arcsin\dfrac{\alpha-1}{\alpha+1}$，出现在 $\omega_m=\dfrac{1}{T\sqrt{\alpha}}$
- 滞后校正降高频增益、提稳态精度；超前校正提快速性与裕度

**状态空间**

- 能控性判据 $\mathrm{rank}\,[B\ \ AB\ \ \cdots\ \ A^{n-1}B]=n$
- 能观性判据 $\mathrm{rank}\,[C;\ CA;\ \cdots;\ CA^{n-1}]=n$

**机器人**

- DH 齐次变换 $A_i=\mathrm{Rot}_z(\theta_i)\,\mathrm{Trans}_z(d_i)\,\mathrm{Trans}_x(a_i)\,\mathrm{Rot}_x(\alpha_i)$
- 正运动学 $T_0^n=A_1A_2\cdots A_n$
- 逆解存在性与奇异位形：雅可比矩阵 $\det J=0$ 时失去一个自由度方向

## 高频考点

- 方框图化简最后一步最容易错：把反馈支路符号搞反。
- 根轨迹：$n-m$ 条渐近线，角度 $\dfrac{(2k+1)180°}{n-m}$，与实轴交点 $\sigma_a=\dfrac{\sum p-\sum z}{n-m}$。
- Bode 图手画：先画低频渐近线（斜率 $-20\nu$ dB/dec），再逐环节叠加转折点。
- DH 建表：关节变量是 $d$ 还是 $\theta$ 取决于关节类型，建表前先标清楚。
- 拉格朗日动力学：$L=K-P$，$\dfrac{d}{dt}\dfrac{\partial L}{\partial\dot q}-\dfrac{\partial L}{\partial q}=\tau$。
