## 用法建议

1. **对考点**：先用 [../去年重点-贾云飞陆体文/](../去年重点-贾云飞陆体文/) 的照片定位页码，再回到 2025 这套 PDF 里读原页；
2. **对疑难点**：2021 许虹那套图多、例题多（铸造 191 页），讲得比 2025 细；
3. **老 .ppt 打不开时**：WPS / PowerPoint 都能打开，直接双击即可，不用另存。
