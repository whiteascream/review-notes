## 和其他资料的关系

- 铸造部分的划线页（01–07）与 [../../exercises/习题解答-索引.md](../../exercises/习题解答-索引.md) 里 p17–p30 的图例题**高度重合**：老师讲到哪，习题册就练到哪，15 分大题就在 p80 那一节。
- 锻压 + 冲压（08–19）覆盖了今年简答第 2、3 题和结构改错第 2 题的全部知识点。
- 焊接（20）直接对应简答第 4 题——只有这一页，说明老师当时只抓了热影响区。
- 复习优先顺序：**06（15 分原题所在节）→ 04 → 20 → 09/10 → 16 → 15**。
