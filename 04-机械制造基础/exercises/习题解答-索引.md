## 二、考前必看：p21–p30

同学回忆：本次 15 分综合大题**就是这堆图里的原题**，问法改成「**单件生产**条件下用哪种造型方法」。逐页要点：

| 页 | 题目 | 答案要点 |
|---|---|---|
| p21 | 轴承件两种分型方案 | 两方案均可行；方案Ⅰ有**错箱**可能；方案Ⅱ**整模造型**操作简单、质量高、冒口易安放 → 方案Ⅱ稍好 |
| p22 | 分型面应尽量为平直面 | 方案Ⅰ分型面为**曲面**不利分型；方案Ⅱ分型面在**最大截面**处且为**平面** → 可行 |
| p23 | 四个分型方案（Ⅰ~Ⅳ）评价 | Ⅰ：φ125 两圆台凸起**妨碍拔模**、轴头孔型芯头复杂；Ⅱ：底部 A 处妨碍拔模、有错箱；Ⅲ：仅错箱；Ⅳ：分型面处有圆弧需**挖砂**、顶部圆台妨碍拔模 |
| p24 | 槽轮件：两个分型面 vs 一个 | 分型面**越少越好**（简化造型、减少错箱）；一个分型面 + 环状型芯 → 整模二箱机器造型最佳 |
| p25–p26 | 大批量生产选方案 | 方案Ⅱ型芯稳但 φ18 凸台需 4 个活块；方案Ⅰ整模/分开模、铸件全在下箱 → 大批量选方案Ⅰ |
| p27 | 三种分型方案比较 | 小批选Ⅱ（挖砂）更经济；大批选Ⅲ（分开模，省活块/挖砂）费用低 |
| p28 | 浇注位置：加工面朝哪 | **重要加工面或工作面朝下**（或翻立），采用分模方案 |
| p29 | 立柱件：顺序凝固 vs 平作立浇 | 方案Ⅰ φ12 凸台妨碍拔模；方案Ⅱ可顺序凝固但立柱太高、内壁修型难 → 用方案Ⅰ「**平作立浇**」（轴线分型→下芯→合箱→翻转 90° 浇注） |
| p30 | 结构斜度 vs 拔模斜度 | 结构斜度：零件图上**非加工面**的斜度，值**大**；拔模斜度：工艺图上为起模在垂直分型面各侧面设的斜度，值**小**；有结构斜度的表面**不再加**拔模斜度 |

## 三、用法

1. **刷题**：先用 PPT 版（材料网）过一遍题目和答案，再回本册看带图的解析。
2. **对答案**：错题记到 [../exercises/mistake-log.csv](../../templates/mistake-log.csv) 或本册页码旁。
3. **考前 1 天**：只看本表第二节（p21–p30）+ [判断题精解](../notes/判断题精解-61题.md)。
