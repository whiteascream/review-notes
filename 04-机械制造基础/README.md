## 必背清单（考前一眼）

**切削**

- 正交平面内角度关系 $\gamma_o+\alpha_o+\beta_o=90°$
- 切削速度 $v_c=\dfrac{\pi dn}{1000}$（m/min，$d$ 为 mm）
- 三要素影响：$v_c$ 高 → 表面质量好、刀具磨损快；$f$ 大 → 效率高、粗糙度差；$a_p$ 大 → 效率高、切削力大
- 刀具磨损三阶段：初期磨损 → 正常磨损 → 剧烈磨损，正常磨损阶段是刀具寿命区间

**定位**

- 六点定位原理：3（底面）+ 2（侧面）+ 1（端面）
- 欠定位 = 该限制的自由度没限制；过定位 = 同一自由度被重复限制
- 夹紧力方向：指向主要定位面、与切削力/重力同向、作用点落在支承范围内

**尺寸链**

- 封闭环 $A_0=\sum A_i^{+}-\sum A_i^{-}$
- 极值法封闭环公差 $T_0=\sum T_i$；封闭环上/下偏差按增减环分别累加
- 基准不重合时用「工序尺寸换算」，别直接照抄设计尺寸

**工艺性**

- 铸造：最小壁厚、铸造圆角、起模斜度、避免铸件收缩受阻 → 缩孔（集中）与缩松（分散）
- 焊接：热影响区组织变化、焊接顺序减少变形、焊后矫正
- 表面粗糙度 Ra 与加工方法：粗车 12.5~6.3、精车 3.2~1.6、磨削 0.8~0.2、研磨 0.1 以下

## 高频考点

- 刀具角度标注题：先找基面（平行刀杆底面）与前刀面，再标 $\gamma_o$、$\alpha_o$、$\kappa_r$、$\lambda_s$，方向错一个就全错。
- 定位方案分析：画自由度表，逐个数「限制了几个」比死记结论可靠。
- 尺寸链：先分清增环/减环（箭头同向为增），再套极值法；概率法只在题目明确要求时用。
- 工艺路线排序：「先粗后精、先面后孔、先主后次、基准先行」。
- 误差复映：毛坯误差在加工后按 $C$ 倍复映到工件上，粗加工后必须安排半精加工。
