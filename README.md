## 每个学科目录里有什么

```
NN-学科/
├─ README.md      # 本学科主页：教材、考试形式、章节目录、必背清单
├─ notes/         # 章节笔记，一章一份
├─ formulas/      # 公式速查表（能打印，一科一张）
├─ exercises/     # 习题、典型题、错题本
├─ exam/          # 真题、模拟题、老师划的重点
├─ summary/       # 考前速览、一页纸总结
├─ labs/          # 实验报告与整理（有实验课的学科才建）
└─ assets/        # 本学科用到的图、截图
```

| 目录 | 放什么 | 不放什么 |
|---|---|---|
| `notes/` | 概念、推导主线、例题、易错点 | 教材原文照抄 |
| `formulas/` | 公式 + 适用条件 + 单位 | 没有适用条件的公式堆砌 |
| `exercises/` | 做过的题、错题本 CSV | 只存不做的题海 |
| `exam/` | 真题、模拟卷、考点清单 | 他人付费资料、扫描版教材 |
| `summary/` | 一页纸、考前 3 天清单 | 长文 |
| `labs/` | 实验报告原件 + 数据/思考题整理 | 只有照片没有整理 |
| `assets/` | 图、截图、手写拍照 | 视频、CAD 大文件 |

## 命名规范

| 类型 | 示例 |

中文文件名可以正常用，仓库网页会做百分号编码，不影响访问。

## 复习节奏：三轮法

| 轮次 | 时间点 | 动作 | 产出 |
|---|---|---|---|
| 第一轮 · 建骨架 | 考前 3–4 周 | 通读教材，只填章节目录与概念表，**不抄书** | `notes/` 每章一页 |
| 第二轮 · 做透 | 考前 2 周 | 每章 3–5 道典型题，错的进 `mistake-log.csv` | 错题本能二刷 |
| 第三轮 · 压缩 | 考前 3 天 | 每章压成一条公式 + 一句话复述 | `formulas/`、`summary/` |
| 冲刺 | 考前 1 天 | 只看 `summary/` 与 [考前速览清单](templates/exam-review.md) | 不动新题 |

判断「会了」的标准：合上书写出章节标题，合上书讲出公式的适用条件。做不到就是还没会。

## 怎么往里加资料

网页直接编辑（改小东西最快）：在 GitHub 上打开文件 → 右上角铅笔 → 提交。

本地命令行：

```bash
git add .
git commit -m "机械设计: 第7章 齿轮传动"
git push
```

新开一门课：复制 `templates/subject-README.md` 到 `NN-新学科/README.md`，再建 6 个子目录（空目录加 `.gitkeep`）。（有实验课的再建 `labs/`。）

## 公开仓库注意事项

- 只放**自己写的**内容。教材原文、扫描版真题、他人付费讲义、网课讲义不上传——这是版权问题，不是效率问题。
- 不放个人信息：学号、班级、姓名、成绩、老师联系方式。
- 大文件：优先截图或导出 PDF；单个文件超过 50MB 会警告、超过 100MB GitHub 直接拒收，大资料用网盘链接代替。
- CAD 模型、仿真结果（`.sldprt`、`.db`、`.rst` 等）已在 [`.gitignore`](.gitignore) 中排除，避免仓库变臃肿。
- 本仓库是个人复习整理，不构成任何教材或课程的官方资料。
