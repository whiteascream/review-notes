## 必背清单（考前一眼）

**齿轮**

- 分度圆直径 $d=mz$，中心距 $a=\dfrac{m(z_1+z_2)}{2}$
- 接触疲劳强度 $\sigma_H=Z_EZ_HZ_\varepsilon\sqrt{\dfrac{2KT_1(u+1)}{bd_1^2u}}\le[\sigma_H]$
- 齿根弯曲强度 $\sigma_F=\dfrac{2KT_1Y_{Fa}Y_{Sa}}{bd_1m}\le[\sigma_F]$
- 直齿轮切向力 $F_t=\dfrac{2T_1}{d_1}$，径向力 $F_r=F_t\tan\alpha$

**带传动**

- 传动比 $i=\dfrac{n_1}{n_2}=\dfrac{d_2}{d_1(1-\varepsilon)}$，$\varepsilon$ 为弹性滑动率
- V 带根数 $z=\dfrac{P_{ca}}{(P_0+\Delta P_0)K_\alpha K_L}$
- 失效形式：打滑（过载）与疲劳（带断裂）；防止打滑靠张紧与原包角

**链传动**

- 链节数 $L_p=\dfrac{2a}{p}+\dfrac{z_1+z_2}{2}+\dfrac{p}{a}\left(\dfrac{z_2-z_1}{2\pi}\right)^2$（取偶）
- 链轮齿数 $z_1\ge17$，$z_1$ 太小加剧多边形效应

**轴**

- 扭转初估 $d\ge A_0\sqrt[3]{\dfrac{P}{n}}$
- 弯扭合成 $\sigma_{ca}=\dfrac{\sqrt{M^2+(\alpha T)^2}}{W}\le[\sigma_{-1}]$

**轴承**

- 寿命 $L_{10}=\left(\dfrac{C}{P}\right)^{\varepsilon}$，球轴承 $\varepsilon=3$，滚子 $\varepsilon=10/3$
- 当量动载荷 $P=XF_r+YF_a$；$F_a/F_r\le e$ 时 $P=F_r$

**连接**

- 第四强度理论 $\sigma_{ca}=\sqrt{\sigma^2+3\tau^2}$
- 受轴向工作载荷 $F$ 的紧螺栓：$F_2=F_0+\dfrac{C_b}{C_b+C_m}F$，残余预紧力 $F_1=F_2-F$

## 高频考点

- 螺栓组受力分析：先找出受力最大的螺栓，再按单个螺栓校核。
- 齿轮受力方向：用「左右手定则」判螺旋方向与转向的组合，最容易错。
- 结构改错：轴承定位与游隙、密封与端盖、键槽位置、退刀槽、圆角与倒角、螺栓通孔。
- 轴系设计：定位轴肩高度、套筒与轴肩配合、两个轴承的固定方式（一端固定一端游动 / 两端固定）。
